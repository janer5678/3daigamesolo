# 3daigamesolo

A downhill skateboarding game in Unity 6 (6000.4.0f1), styled after the Pururin world from J's World: flat pastel cel shading, ink outlines, pink haze, teal pines, a pink dirt run and a cyan river, with faint TV scanlines over the top.

Open the project and play `Assets/Scenes/SkatePark.unity`. You start at the top of the run. It winds about 650 m down the valley past kickers, rails and ledges, and ends in a flat plaza with a halfpipe, a funbox, rails, a manual pad and a big quarterpipe wall.

## Controls (keyboard + mouse)

| Key | On the ground | In the air | On a rail |
|---|---|---|---|
| **W** | push / pump down slopes and ramps | with a flip: harder flip | nosegrind (held as you land on it) |
| **S** | brake | with a flip: varial flip | 5-0 (held as you land on it) |
| **A / D** | steer | spin | balance |
| **Space** | hold to crouch, let go to ollie (longer hold = higher) | | pop off |
| **Shift** | manual (W/S to balance) | grab (W nose, S tail, A/D melon) | |
| **LMB / RMB** | | kickflip / heelflip | |
| **Q / E** | | pop shove-it / 360 shove-it | |
| **Mouse** | look around (it swings back behind you) | | |
| **R** | restart at the top | | |
| **H** | show/hide controls | | |

**Easy to pick up:** the board always rolls the way it points. Any landing within about 70° of straight is saved and straightened out for you. Rails snap you on when you get close. Ollie height is just how long you hold Space.

**Room to get good:**
- **Perfect landings** (within 12°, not grabbing) give +1 combo multiplier and a speed boost.
- **Flips have to come round** before you touch down, or you bail. The same flip twice in one air becomes a Double, then a Triple.
- **Grinds and manuals have a balance** that drifts and gets harder the longer you hold it.
- **Repeating a trick** in the same combo scores less each time.
- **Manuals link combos.** Hold Shift through a landing to keep the combo going.
- **Pump with W** on the way down transitions to get higher on the halfpipe.

## Rebuilding the world

The scene is generated by `Assets/Editor/SkateWorldBuilder.cs` (menu **Skate > Build world**). Change the layout there and rebuild rather than editing the scene by hand. **Skate > Run test rides** drives the real controller through a set of scripted runs (coast, ride the run, kickflip, 360, big kicker, rail grind, quarterpipe, halfpipe, manual) and logs PASS/FAIL to the console.

Command line:

```
Unity -batchmode -projectPath . -executeMethod SkateWorldBuilder.BuildFromCommandLine   # build + tests + screenshots in Review/
Unity -batchmode -projectPath . -executeMethod SkateWorldBuilder.BuildPlayer            # Windows build in Builds/Windows
```

The shaders in `Assets/Shaders` are adapted from J's World's Pururin world shaders. The HUD font is Bangers (SIL Open Font License, see `Assets/Resources/Bangers - OFL.txt`).
