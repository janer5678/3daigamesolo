# 3daigamesolo

A first-person downhill sliding game in Unity 6 (6000.4.0f1), styled after the Pururin world from J's World: flat pastel cel shading, ink outlines, pink haze, teal pines, a pink dirt run and a cyan river, with faint TV scanlines over the top.

Open the project and play `Assets/Scenes/SkatePark.unity`. You start at the top of the run. It winds about 650 m down the valley past kickers, rails and ledges, and ends in a flat plaza with a halfpipe, a funbox, rails, a manual pad and a big quarterpipe wall.

## Controls

First person, standing on a board (look down and it's there). Grippy and fast, not slidy: you get up to speed almost straight away, and you stop about a second after letting go. Speed picked up going downhill is kept, and steering turns it rather than braking it.

| Key | |
|---|---|
| **Mouse** | look |
| **WASD** | move (about 40 km/h) |
| **Shift** (hold) | push to about 80 km/h; on its own it pushes you forward |
| **Space** | jump (a small hop; you can steer in the air with WASD) |
| **R** | back to the start |
| **Esc / click** | free / recapture the mouse |

Tuning lives on the Player object's `SlideController`: run speed, push speed, how fast you speed up and stop, how sharply downhill speed turns, jump, and the overall cap (about 108 km/h).

The skateboard version (tricks, grinds, manuals, combos) is in git history at commit `7130f56`.

## Rebuilding the world

The scene is generated by `Assets/Editor/SkateWorldBuilder.cs` (menu **Skate > Build world**). Change the layout there and rebuild rather than editing the scene by hand. **Skate > Run test rides** steps the real controller and physics through a few scripted runs (speeds up fast, stays put when idle, push all the way down the run, stops when you let go, jump height and air control) and logs PASS/FAIL to the console.

Command line:

```
Unity -batchmode -projectPath . -executeMethod SkateWorldBuilder.BuildFromCommandLine   # build + tests + screenshots in Review/
Unity -batchmode -projectPath . -executeMethod SkateWorldBuilder.BuildPlayer            # Windows build in Builds/Windows
```

The shaders in `Assets/Shaders` are adapted from J's World's Pururin world shaders. The HUD font is Bangers (SIL Open Font License, see `Assets/Resources/Bangers - OFL.txt`).
