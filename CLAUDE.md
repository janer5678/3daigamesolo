# 3daigamesolo - notes for Claude

## When a new prompt arrives: close the game

The user wants the game closed as soon as they send a prompt. `.claude/settings.json` has a `UserPromptSubmit` hook that does this; if it didn't run (the game is still open), close it yourself first:
`Get-Process 3daigamesolo -ErrorAction SilentlyContinue | Stop-Process -Force`

## After making changes: rebuild and open the game

Whenever you change anything in this project, finish by building the game and opening it so it can be played straight away:

1. Rebuild the scene and run the test rides (Unity must be closed for batch mode):
   `"C:/Program Files/Unity/Hub/Editor/6000.4.0f1/Editor/Unity.exe" -batchmode -projectPath "C:/Users/OEM/Documents/GitHub/3daigamesolo" -executeMethod SkateWorldBuilder.BuildFromCommandLine -logFile <scratchpad>/build.log`
   then check the log for `error CS` and `SLIDE_TEST FAIL`.
2. Close any copy of the game that's already running (an older build; it also locks the files the build overwrites):
   `Get-Process 3daigamesolo -ErrorAction SilentlyContinue | Stop-Process -Force`
3. Make the Windows build:
   `... -executeMethod SkateWorldBuilder.BuildPlayer -logFile <scratchpad>/player.log` (look for `SKATE_PLAYER_BUILD Succeeded`).
4. Open the new build for the user (detached, windowed, no `-autoshot`), so only the most recent build is running:
   `Start-Process "C:\Users\OEM\Documents\GitHub\3daigamesolo\Builds\Windows\3daigamesolo.exe"`

If a step fails, say so instead of opening an old build.

## Project notes

- The scene `Assets/Scenes/SkatePark.unity` is generated by `Assets/Editor/SkateWorldBuilder.cs`. Change the builder and rebuild; don't hand-edit the scene.
- Movement is `Assets/Scripts/SlideController.cs` (walk by default, hold Shift to ride the board). Tests are `Assets/Editor/SlideTests.cs`; add a test when changing how movement feels.
- `-autoshot <folder>` on the built exe takes screenshots and quits (`SkateAutoShot.cs`). It reads real keyboard input even in the background, so keys pressed while it runs show up in the results.
