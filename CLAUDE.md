# 3daigamesolo - notes for Claude

## Don't close the game while working

The user plays while you work: never close the game when a prompt arrives or while building. Only at the very end, once the new build has succeeded, swap it over (step 3 below).

## After making changes: rebuild and open the game

Whenever you change anything in this project, finish by building the game and opening it so it can be played straight away:

1. Rebuild the scene and run the test rides (Unity must be closed for batch mode):
   `"C:/Program Files/Unity/Hub/Editor/6000.4.0f1/Editor/Unity.exe" -batchmode -projectPath "C:/Users/OEM/Documents/GitHub/3daigamesolo" -executeMethod SkateWorldBuilder.BuildFromCommandLine -logFile <scratchpad>/build.log`
   then check the log for `error CS` and `SLIDE_TEST FAIL`.
2. Make the Windows build. It goes to `Builds/Staging`, so the copy the user is playing (in `Builds/Windows`) isn't touched:
   `... -executeMethod SkateWorldBuilder.BuildPlayer -logFile <scratchpad>/player.log` (look for `SKATE_PLAYER_BUILD Succeeded`).
3. Only if that succeeded: close the running game, copy the new build over, and open it, so only the most recent build is running:
   `Get-Process 3daigamesolo -ErrorAction SilentlyContinue | Stop-Process -Force; Start-Sleep -Milliseconds 800; robocopy Builds\Staging Builds\Windows /MIR /NJH /NJS /NP | Out-Null; Start-Process "C:\Users\OEM\Documents\GitHub\3daigamesolo\Builds\Windows\3daigamesolo.exe"`

If a step fails, say so instead of opening an old build (and leave the user's game running).

## Project notes

- The scene `Assets/Scenes/SkatePark.unity` is generated by `Assets/Editor/SkateWorldBuilder.cs`. Change the builder and rebuild; don't hand-edit the scene.
- Movement is `Assets/Scripts/SlideController.cs` (walk by default, Q gets on and off the board, Shift pushes). Tests are `Assets/Editor/SlideTests.cs`; add a test when changing how movement feels.
- `-autoshot <folder>` on the built exe takes screenshots and quits (`SkateAutoShot.cs`). It reads real keyboard input even in the background, so keys pressed while it runs show up in the results.
